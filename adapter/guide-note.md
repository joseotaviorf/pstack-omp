> **In omp.** Install pstack with `omp plugin marketplace add joseotaviorf/pstack-omp` and `omp plugin install pstack@pstack-omp`. Update it with `omp plugin marketplace update pstack-omp` and `omp plugin upgrade pstack@pstack-omp`. Then type each command in these docs as `/skill:<name>`, such as `/skill:setup-pstack`. In place of a Custom Mode, `/poteto-mode on` keeps poteto mode on in every turn of the session, until `/poteto-mode off`. Steps that need a Cursor-only feature are skipped in omp. Those features are cloud agents and Projects, and automations, including the benny pack. The `pstack-omp-adapter` skill maps the rest.
